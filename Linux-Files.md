#Files

```
Everything is a file

Linux does not look at file extensions to figure out what type of file a file 
unlike in Windows; rather it looks at the contents of the file

file [path] - to figure out the file type

##Linux is case senstive

##Quotes

Use them to locate certain files such as ones with space in between the words

cd 'Holiday Photos'

or use a backslash to escape the special character

cd Holiday\ Photos

##Hidden Files

We can create a hidden file by using a '.' at the start of the file

e.g. touch .myhiddenfile.txt

Renaming it without the '.' makes it a regular file

to view hidden files use 


ls -a [path]


```
