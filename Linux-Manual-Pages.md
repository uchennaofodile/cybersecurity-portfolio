#Manual Pages

```
man [command to look up] 

tells you what that command does and how to use it

man -k [search term]

useful if you're not sure what command you need

eg to find a command to spell check a file

use man -k spell

use sudo mandb to update manuals if you keep getting nothing returned

/[term] once in a manual page to search for a specific term

n -to go to the next instance of that term



```
